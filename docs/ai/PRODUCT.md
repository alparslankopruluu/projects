# Product

Projects is an operations desk for a small studio with many apps. It answers what needs a human today, where each release sits, and what the next coding session must already know.

It is not a second analytics suite and not a checklist of unrelated boxes. Store review, a missing Play listing, and an unlaunched ad plan are different kinds of work.

Stack: Next.js, local-first state, optional Firebase. GitHub sync writes `docs/project-brief.md` and ignores its own "Update project brief" commits.
